# Expert-Text-Enhanced Ego-Exo-Pose Proficiency Estimation

This folder contains the reproducible exploratory analyses for demonstrator
proficiency estimation with four aligned modalities:

1. egocentric RGB video;
2. exocentric RGB video;
3. 3D body pose; and
4. timestamped expert commentary text.

The repository includes exploratory analyses and the first timestamp-level
four-class proficiency baselines. The reported experiment uses a controlled
52-take subset where all four planned inputs are aligned.

## Reproducing the analyses

The scripts expect a local Ego-Exo4D subset with:

```text
egoexo4d_subset/
  selected_takes_128.csv
  takes/
  annotations/
    proficiency_demonstrator_train.json
    ego_pose/
    expert_commentary/
```

From this directory, run:

```powershell
python audit_text_video_pose.py --data-root <path-to-egoexo4d_subset> --output-root outputs/coverage
python analyze_expert_text.py --data-root <path-to-egoexo4d_subset> --output-root outputs/text
python analyze_video_features.py --data-root <path-to-egoexo4d_subset> --output-root outputs/video --weights <path-to-resnet50-11ad3fa6.pth>
python train_baseline.py --data-root <path-to-egoexo4d_subset> --weights <path-to-resnet50-11ad3fa6.pth> --output-root outputs/baseline
```

`analyze_expert_text.py` uses the locally cached
`sentence-transformers/all-MiniLM-L6-v2` model to avoid an unexpected network
download during reproduction.

## Verified results

* 128 takes contain ego and exo video.
* 52 takes contain the complete ego+exo+pose+aligned-expert-text input set.
* The pose-covered subset contains 1,682 aligned text segments, with a median
  of 35 segments per take.
* The 120 commentary documents have activity/proficiency silhouette scores of
  0.18695/0.00753 using normalized MiniLM embeddings.
* ResNet-50 visual features are more structured by activity than proficiency.
  Exact raw-feature metrics are in `results/video_metrics.json`.

The visual silhouette scores are computed on the original ResNet feature
vectors. t-SNE is used only to visualize those vectors.

## First baseline

`train_baseline.py` uses frozen ImageNet ResNet-50 features from six uniformly
sampled ego and exo frames per take. It normalizes each 3D pose frame at the
hip center and by shoulder width, summarizes joint positions and velocities,
then concatenates the modality features for a balanced logistic-regression
classifier. The text-enhanced condition mean-pools masked MiniLM embeddings of
the take's timestamped expert-commentary segments. Evaluation uses 3-fold
stratified participant-disjoint cross-validation over the 52 takes with ego,
exo, pose, and expert text.

The visual-only baseline metrics are in `results/baseline_metrics.json`; the
text-enhanced run is in `results/baseline_text_metrics.json`. On this small,
participant-disjoint subset, exo-only achieved the best visual-only macro-F1
(0.416), simple ego+exo+pose concatenation achieved 0.336, and
ego+exo+pose+masked expert text achieved 0.400. These are frozen-feature
baseline results, not evidence that pose is unhelpful: the fusion model is
deliberately simple and the subset has only three Novice takes.

## Timestamp-level fusion baseline

The timestamp-level experiment uses the 52 takes for which all four official
inputs are available. It treats each timestamped expert comment as an interval,
extracts a short synchronized Ego and Exo window around that timestamp,
summarizes nearby 3D pose frames, and masks direct proficiency rating terms in
the text. Segment logits are mean-pooled within a take before the four-level
proficiency loss and metrics are calculated.

Run feature extraction once:

```powershell
python extract_interval_features.py --data-root <data-root> --manifest <four-modality-manifest> --weights <resnet50-weights> --output interval_fusion_results/aligned_interval_features.npz --metadata-output interval_fusion_results/aligned_interval_metadata.json
```

Then run the participant-disjoint comparison:

```powershell
python train_interval_fusion.py --features interval_fusion_results/aligned_interval_features.npz --metadata interval_fusion_results/aligned_interval_metadata.json --output-dir interval_fusion_results
```

The output contains Ego+Exo, Ego+Exo+Pose, Ego+Exo+Pose+aligned masked text,
and masked-text-only models. The proposed model is also evaluated after its
held-out text segments are shuffled within each take, preserving person,
activity, and label but breaking comment-to-moment alignment.

## Reported visual-pretrained pilot

The midterm report uses a three-commentary-interval-per-take pilot: 156
intervals from the 52 takes with aligned Ego, Exo, pose, and expert text.
The visual projectors are initialized on a separate 289-take Ego+Exo-only
cohort; none of the 52 pilot takes are in that initialization cohort.

The final participant-disjoint results are saved in
`interval_fusion_results/pilot_visual_pretrained/interval_fusion_metrics.json`:

| Model | Accuracy | Balanced accuracy | Macro-F1 |
| --- | ---: | ---: | ---: |
| Ego+Exo | 44.2% | 46.9% | 41.0% |
| Ego+Exo+Pose | **51.9%** | **53.3%** | 51.0% |
| Ego+Exo+Pose+aligned masked text | 50.0% | 51.8% | **51.7%** |
| Ego+Exo+Pose+shuffled text | 49.8% | 52.5% | 47.9% |
| Masked text only | 44.2% | 47.4% | 44.7% |

Feature arrays and learned checkpoints are deliberately excluded from Git.
They can be regenerated from an authorized local Ego-Exo4D download using the
selection, extraction, pretraining, and interval-fusion scripts above.
